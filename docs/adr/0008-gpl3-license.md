# ADR 0008 — 许可证选择 GPL-3.0-or-later

## 状态
已采纳（2026-11-03）

## 背景
基线 g0wm 是 GPL-3.0-or-later（其上游 dwl、sway、tinywl 片段亦为 GPL 系）。
r0wm 是 Rust 重写，但「功能全等」的目标意味着实现过程中会反复对照基线的具体逻辑
（bar 的测量与布局、行列规则、通知的 D-Bus 交互等）。

## 决策
r0wm 采用 **GPL-3.0-or-later**。

## 权衡
- MIT / Apache-2.0：与 Smithay 一致，生态采用门槛最低；但只要有一个函数是"照着
  G0wm 的 C 代码改写成 Rust"，它就是演绎作品，宽松许可证会直接踩线。要保住宽松
  许可必须严格 clean-room（只读文档、不读实现），与 parity 目标冲突，成本显著更高。
- 暂不决定：越晚定越难改，贡献者需要追认。
- 选 GPL 的代价：借用 r0wm 代码的下游项目必须同样 GPL；也想排除把 r0wm 代码搬进
  宽松许可项目的情形。
